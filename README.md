# Sales Database SQL Assignment

## 1. About This Project

This project is my Week 2 SQL assignment.
It uses a database called `sales`.

The `sales` database stores data for a company
that sells model cars. It has 8 tables:

- `productlines`
- `products`
- `offices`
- `employees`
- `customers`
- `payments`
- `orders`
- `orderdetails`

The goal is to practise the basics of SQL.
These are the skills used in this project:

- Selecting specific columns with `SELECT`
- Filtering rows with `WHERE`
- Sorting results with `ORDER BY`
- Limiting results with `LIMIT`
- Reading data from different tables

All the code is in one file:
`sales_assignment.sql`
